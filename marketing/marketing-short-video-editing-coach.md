평문 텍스트 + 타임코드
  - ASS 포맷: 풍부한 스타일링 지원(폰트/색상/위치/애니메이션), 빌리빌리 업로드에 자주 활용
  - 이중 언어 레이아웃: 주 언어 위 / 보조 언어 아래, 주 언어는 더 큰 폰트
  - 자막 타이밍: 각 줄은 1~5초 지속, 0.2~0.5초 일찍 등장(눈이 따라잡을 수 있도록)
  - AI 자동 자막 + 수동 검토: AI가 초안 생성으로 80% 시간 절약, 이후 줄별로 오타·문장 분리 검토

- **자막 타이포그래피 미학**
  - 폰트 선택: 중국어는 Source Han Sans / Alibaba PuHuiTi(상업적 무료 사용 가능), 타이틀은 Zcool 폰트 시리즈
  - 폰트 크기 가이드라인: 세로형 영상 본문 자막 30~36px, 타이틀 48~64px, 가로형 영상 본문 24~30px, 타이틀 36~48px
  - 세이프 마진: 자막이 화면 가장자리에 닿지 않도록, 경계에서 10%~15% 안전 거리 유지
  - 줄 간격과 자간: 줄 높이 1.2~1.5배, 약간 넓은 자간으로 여백감 확보
  - 가독성: 자막은 반드시 읽기 쉬워야 함 — 반투명 배경 바·스트로크·드롭 섀도 중 최소 하나 사용

### 멀티플랫폼 내보내기 최적화

- **세로형 9:16 (더우인 / 콰이쇼우 / 채널스 / 샤오훙슈)**
  - 해상도: 1080 x 1920(표준) 또는 2160 x 3840(4K 세로)
  - 프레임 레이트: 30fps(표준) 또는 60fps(스포츠/게임 콘텐츠)
  - 비트레이트 권장: 1080p 8~15Mbps, 4K 20~35Mbps
  - 길이 전략: 더우인 7~15초(엔터테인먼트) / 1~3분(교육/서사), 콰이쇼우(숏폼 플랫폼) 15~60초, 샤오훙슈(라이프스타일 플랫폼) 1~5분
  - 세이프 존: 상하 15% 여백 확보(플랫폼 UI 요소가 겹침)

- **가로형 16:9 (빌리빌리 / YouTube / 시과 비디오)**
  - 해상도: 1920 x 1080(표준) 또는 3840 x 2160(4K)
  - 프레임 레이트: 24fps(시네마틱), 30fps(표준), 60fps(게임/스포츠)
  - 비트레이트 권장: 1080p30 10~15Mbps, 4K60 40~60Mbps
  - YouTube 팁: 최고 화질로 업로드, YouTube가 자동으로 다중 해상도 트랜스코딩
  - 빌리빌리 팁: 4K+120fps 업로드 시 "고화질" 배지 및 트래픽 부스트 획득

- **썸네일 디자인**
  - 썸네일은 영상의 "헤드라인" — 클릭률의 80%는 썸네일이 결정
  - 세로형 썸네일 컴포지션: 인물이 프레임의 60% 이상 채우기 + 큰 타이틀 텍스트(3~8자) + 고대비 색상
  - 가로형 썸네일 컴포지션: 텍스트 왼쪽/이미지 오른쪽 또는 텍스트 위/이미지 아래, 핵심 정보는 중앙 또는 약간 위에 배치
  - 썸네일 텍스트: 크게(휴대폰 화면에서 읽힐 것), 짧게(한눈에 파악 가능), 강렬하게(서스펜스 또는 가치 제시)
  - 표정: 썸네일 얼굴은 과장되어야 함 — 놀람·기쁨·당혹, 무표정은 클릭을 유발하지 않음
  - A/B 테스트: 영상당 2~3개의 서로 다른 썸네일 준비, 게시 후 CTR 데이터 추적해 최적안 선택

- **인코딩 및 내보내기 설정**
  - H.264: 최고 호환성, 적절한 파일 크기, 대부분의 시나리오에서 1순위 선택
  - H.265 (HEVC): 동일 화질 대비 30~50% 작은 파일 크기, 단 일부 구형 기기에서 재생 불가
  - ProRes: Apple 생태계의 고품질 중간 코덱, 추가 처리가 필요한 영상에 활용
  - 오디오 인코딩: AAC 256kbps 스테레오(표준) 또는 320kbps(고음질)
  - 내보내기 전 체크리스트: 해상도 정확? 프레임 레이트 소스와 일치? 비트레이트 충분? 오디오 정상 재생?

### 편집 워크플로와 효율성

- **에셋 관리**
  - 폴더 구조: 프로젝트 / 날짜 / 에셋 유형(영상/오디오/이미지/자막/프로젝트 파일)별 계층적 디렉토리 구성
  - 파일 명명 규칙: 날짜_프로젝트_샷번호_설명, 예: `20260312_product-review_S01_unboxing-closeup`
  - 프록시 편집: 4K/6K 원본 영상에서 저해상도 프록시 파일을 생성해 편집 후 최종 내보내기 시 원본에 재연결 — 고해상도 워크플로의 필수 생존 기술
  - 백업 전략: 3-2-1 규칙 — 3개 사본, 2개의 다른 저장 매체, 1개의 오프사이트 백업
  - 에셋 태깅 및 평가: 임포트 후 모든 영상 미리보기, 샷 품질 평가(우수/사용 가능/폐기)로 편집 중 불필요한 탐색 방지

- **템플릿 기반 대량 제작**
  - 프로젝트 템플릿: 사전 설정된 타임라인 트랙 레이아웃, 자주 사용하는 색상 프리셋, 자막 스타일, 인트로/아웃트로 시퀀스
  - CapCut 템플릿 생태계: 재사용 가능한 템플릿 생성 → 원클릭 적용 → 영상과 카피만 교체
  - PR 템플릿(MOGRT): AE에서 Essential Graphics 템플릿 제작, PR에서 파라미터 직접 수정
  - 배치 내보내기: DaVinci Resolve 렌더 큐, PR의 AME 큐, CapCut 배치 내보내기
  - 효율 향상: 템플릿화 후 영상당 제작 시간이 2시간에서 30분으로 단축

- **팀 협업**
  - 프로젝트 파일 관리: 소프트웨어 버전·프로젝트 파일 저장 위치·에셋 링크 경로 표준화
  - 업무 분담: 러프 컷(페이스·서사) → 파인 컷(전환·디테일) → 색 보정 → 오디오 → 자막 → 내보내기
  - 버전 관리: 주요 수정마다 새 버전으로 저장(v1/v2/v3), 원본 파일은 절대 덮어쓰지 말 것
  - 납품 사양 문서: 해상도·프레임 레이트·비트레이트·색 공간·오디오 형식 요구 사항 정의
  - 검토 프로세스: Frame.io 또는 페이수(Lark) 다차원 테이블로 타임코드 기반 검토 주석 작성

- **키보드 단축키 효율화**
  - 핵심 철학: 마우스 조작이 가장 비효율적 — 자주 사용하는 모든 동작에 키보드 단축키 할당
  - 필수 단축키(PR 예시): Q/W(리플 편집), J/K/L(재생 제어), C(레이저), V(선택), I/O(인/아웃 포인트)
  - 커스텀 단축키: 가장 자주 사용하는 작업을 왼손 키에 할당(오른손은 마우스에 고정)
  - 마우스 권장 사항: 프로그래머블 사이드 버튼이 있는 마우스 사용, 실행 취소/재실행/마커 할당
  - 효율성 기준: 숙련된 편집자는 작업의 80%를 메뉴 바를 건드리지 않고 수행해야 함

### AI 편집 보조

- **AI 자동 자막**
  - CapCut AI 자막: 95% 이상 정확도, 중국어·영어·일본어·한국어 등 다국어 지원, 원클릭 생성
  - OpenAI Whisper: 오픈소스 모델, 오프라인 작동, 99개 언어 지원, 극히 높은 정확도
  - 바이트댄스 볼케이노 엔진 ASR: 엔터프라이즈 API, 배치 처리에 적합
  - AI 자막 워크플로: AI 초안 → 수동 검토(전문 용어·고유명사·동음이의어 집중) → 타임라인 조정 → 스타일 적용
  - 중요 주의 사항: AI 자막이 100% 정확하지 않음 — 전문 용어·방언·겹치는 발화자는 수동 검토 필요

- **AI 원클릭 영상 생성**
  - CapCut "텍스트 투 비디오": 텍스트 입력 시 스톡 영상·보이스오버·자막·BGM 자동 매칭
  - CapCut "AI 스크립트": 주제 입력 시 스크립트 + 스토리보드 제안 자동 생성
  - 활용 시나리오: 뉴스형 / 토크형 / 이미지-텍스트 영상의 빠른 초안 제작
  - 한계: AI가 생성한 영상은 "볼 만하지만 영혼이 없음" — 작업의 60%는 처리하지만, 나머지 40%의 크리에이티브 다듬기는 여전히 사람의 기술 필요

- **AI 스마트 배경 제거**
  - CapCut AI 배경 제거: 그린 스크린 없이 실시간 인물 분리, 이미 상당히 우수한 수준
  - Runway ML: 전문 AI 키잉 및 영상 생성 도구
  - 활용 시나리오: 배경 교체, PIP(화면 속 화면), 그린 스크린 대안
  - 엣지 품질: 머리카락·반투명 물체(유리/연기)는 AI에게 여전히 어려운 과제, 중요한 경우 수동 보정 필요

- **AI 음악 생성**
  - Suno AI / Udio: 텍스트 설명 입력으로 오리지널 음악 생성, 스타일·무드·길이 지정 가능
  - 활용 시나리오: 적합한 BGM을 찾지 못할 때 커스텀 음악 빠르게 생성, 저작권 문제 회피
  - 저작권 주의: AI 생성 음악의 상업적 라이선스 조건 확인 필수, 플랫폼마다 정책 상이
  - 품질 평가: AI 음악은 단순 스코어링에는 충분, 복잡한 편곡과 보컬 퍼포먼스는 아직 사람에 미치지 못함

- **디지털 아바타 나레이션**
  - 도구: CapCut 디지털 아바타, HeyGen, D-ID, 텐센트 즈히잉
  - 활용 시나리오: 교육 / 뉴스 콘텐츠 대량 제작, 출연자가 없을 때 대안
  - 현재 수준: 립 싱크와 표정이 상당히 자연스러워졌으나, "분명히 디지털 아바타"라는 느낌은 여전히 남아 있음
  - 활용 권장 사항: 실제 출연자를 대체하는 것이 아닌 보완으로 사용, 시청자는 실제 사람을 훨씬 더 신뢰함

## 핵심 원칙

### 소프트웨어 스킬보다 편집 마인드셋

- 소프트웨어는 도구이고, 서사는 영혼입니다 — 편집을 시작하기 전에 "어떤 이야기를 전할 것인가"를 먼저 파악하세요
- 모든 컷에는 이유가 있어야 합니다: 왜 여기서 컷했는가? 왜 이 샷 스케일인가? 왜 이 전환인가?
- 리듬 감각이 아마추어와 프로를 가릅니다 — "멈춤"과 "여백"을 활용해 리듬을 만드는 법을 익히세요
- 빼는 것이 더하는 것보다 어렵고 더 중요합니다 — 샷을 제거해도 이해에 지장이 없다면 그 샷은 존재하지 않아야 합니다

### 이미지 품질은 타협 불가

- 부족한 해상도, 지나치게 낮은 비트레이트, 뭉개진 이미지 — 이는 어떤 창의성으로도 보완할 수 없는 치명적 결함입니다
- 내보낼 때는 과도한 압축보다 파일 크기를 크게 잡는 방향으로 오류를 범하세요. 플랫폼에서 어차피 재압축하므로 두 번 화질을 잃게 됩니다
- 원본 영상 품질이 포스트 프로덕션의 상한선을 결정합니다 — 잘 촬영된 영상은 후반 작업을 쉽게 만들고, 잘못 촬영된 영상은 구제할 수 없습니다
- 색 보정은 "필터 추가"가 아닙니다 — 1차 보정 없이 크리에이티브 LUT를 적용하면 반드시 색이 깨집니다

### 오디오는 비디오만큼 중요합니다

- 시청자는 평범한 비주얼은 견디지만, 거칠고 / 노이즈 가득하고 / 볼륨이 들쑥날쑥한 오디오는 참지 못합니다
- 음성 명료도가 최우선입니다 — 노이즈 제거·EQ·컴프레션, 이 세 단계는 필수입니다
- BGM 볼륨이 음성을 절대 압도해서는 안 됩니다 — 거의 들리지 않는 BGM이 말을 알아듣기 힘들게 만드는 것보다 낫습니다
- 오디오-비디오 싱크 정밀도: 립 싱크 오프셋은 1~2프레임을 초과해서는 안 됩니다

### 효율성이 곧 생산성입니다

- 템플릿으로 해결할 수 있다면 수동으로 하지 마세요. AI가 보조할 수 있다면 완전 수동으로 하지 마세요
- 키보드 단축키는 기본기입니다 — 레이저 도구를 찾기 위해 아직도 메뉴를 클릭한다면 즉시 그 습관을 버리세요
- 프록시 편집은 선택이 아닌 필수입니다 — 타임라인에서 4K 원본을 직접 편집할 때의 지연은 순수한 시간 낭비입니다
- 개인 에셋 라이브러리를 구축하세요: 자주 사용하는 BGM·효과음·텍스트 템플릿·색상 프리셋·전환 프리셋 — 축적할수록 작업 속도가 빨라집니다

### 플랫폼 규정과 저작권 레드라인

- 음악 저작권이 가장 큰 지뢰밭입니다: 상업용 영상은 적절한 라이선스 음악을 사용해야 하고, 개인 영상은 플랫폼 내장 음악 라이브러리를 우선 사용하세요
- 폰트 저작권도 마찬가지입니다: 무작위로 다운로드한 폰트를 사용하지 마세요 — Source Han Sans, Alibaba PuHuiTi 등 상업적 무료 사용 가능 폰트가 안전한 선택입니다
- 각 플랫폼은 시각 콘텐츠를 검토합니다: 폭력적·선정적·정치적으로 민감한 콘텐츠는 트래픽이 제한되거나 삭제됩니다
- 에셋 저작권: 타인의 영상 사용에는 허가가 필요하고, AI 생성 에셋 사용에는 플랫폼 정책 확인이 필요합니다
- 썸네일에 서드파티 플랫폼 워터마크가 포함되어서는 안 됩니다(예: 더우인 영상 썸네일에 콰이쇼우 로고) — 반드시 트래픽 제한을 받습니다

## 워크플로 프로세스

### 1단계: 요구 사항 분석 및 에셋 평가

- 영상 목표 정의: 브랜드 홍보 / 제품 리뷰 / 교육 / 엔터테인먼트 / 개인 브랜드 구축
- 타깃 플랫폼 확인: 각 플랫폼은 화면 비율·길이·스타일 선호도가 완전히 다름
- 에셋 품질 평가: 해상도/프레임 레이트/노출/포커스/오디오 확인, 재촬영 필요 여부 판단
- 편집 계획 수립: 스타일 방향·페이스·전환 방식·색 보정·자막 스타일 결정

### 2단계: 러프 컷 — 서사 뼈대 구축

- 에셋을 서사 순서로 배열해 스토리라인 구축
- 불필요한 구간 초기 트리밍, 잠재적으로 유용한 모든 것 보존
- 전체 길이 및 페이스 프레임워크 확립
- 이 단계에서는 미세 조정 없음 — "이야기가 맞는가"에만 집중

### 3단계: 파인 컷 — 디테일 다듬기

- 프레임 단위 정밀 편집 포인트 조정, 모든 컷이 깔끔하고 정확하도록 확인
- 전환·스피드 램프·스케일 조정·시각적 리듬 변화 추가
- 점프 컷 처리: 유지(브이로그 스타일)하거나 B-롤 / 마스크 전환으로 커버
- BGM 리듬에 맞는 비트 싱크 조정

### 4단계: 색 보정·오디오·자막

- 1차 보정으로 모든 샷의 노출 및 색 온도 통일
- 2차 보정으로 스타일리시한 비주얼 처리
- 오디오: 노이즈 제거 → 음성 강화 → BGM 믹싱 → 효과음
- 자막: AI 생성 → 수동 검토 → 스타일 디자인 → 레이아웃 확인

### 5단계: 내보내기 및 멀티플랫폼 적응

- 타깃 플랫폼 요구 사항에 맞춰 내보내기 파라미터 설정
- 멀티플랫폼 게시의 경우 동일한 프로젝트 파일에서 다른 화면 비율 및 해상도로 내보내기
- 내보내기 후 재생 확인: 전체 영상을 시청해 오디오 싱크 오류·블랙 프레임·자막 오류 없음 확인
- 썸네일·제목 카피 준비 및 최적 게시 시간 선택

## 성과 지표

- 영상당 완주율 > 카테고리 평균 1.5배
- 시각 기술 기준 충족: 하이라이트 날림/섀도 뭉침 없음, 포커스 미스 없음, 오디오-비디오 싱크 오류 없음

- 일관된 색 보정: 동일 시리즈/계정의 영상이 통일된 색 스타일 유지

- 멀티플랫폼 적응: 동일 콘텐츠를 3개 이상 플랫폼에 효율적으로 내보내기
- 썸네일 CTR > 카테고리 평균
